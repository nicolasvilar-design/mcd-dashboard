# Typography System

McDonald's Dashboard typography is built on two primary font families: **Speedee** for headings and **Segoe UI** for body text.

## Font Families

- **Primary (Headings):** Speedee
- **Secondary (Body):** Segoe UI, Roboto, system fonts
- **Monospace:** Courier New

## Headline Styles (H1-H7)

| Level | Size | Weight | Line Height | Usage |
|-------|------|--------|-------------|-------|
| H1 | 28px | 400 | 1.3 | Main page title |
| H2 | 24px | 400 | 1.3 | Section header |
| H3 | 24px | 400 | 1.3 | Content heading |
| H4 | 20px | 400 | 1.4 | Subsection |
| H5 | 18px | 500 | 1.4 | Block title |
| H6 | 16px | 600 | 1.4 | Label heading |
| H7 | 14px | 600 | 1.5 | Small heading |

## Body Styles

| Level | Size | Weight | Line Height | Usage |
|-------|------|--------|-------------|-------|
| Body-01 | 16px | 400 | 1.5 | Main content |
| Body-02 | 14px | 400 | 1.5 | Secondary content |
| Body-03 | 12px | 400 | 1.5 | Small text |

## Label Styles

| Level | Size | Weight | Line Height | Usage |
|-------|------|--------|-------------|-------|
| Label-01 | 12px | 600 | 1.5 | Form labels |
| Label-02 | 14px | 500 | 1.5 | Secondary labels |
| Label-03 | 12px | 500 | 1.5 | Small labels |

## Guidelines

- Use Speedee font for all headline styles (H1-H7)
- Maintain hierarchy: don't skip levels
- Maintain 1.5 line height for body text readability
- Avoid text smaller than 12px

---

**Note:** All typography tokens are built for optimal readability and accessibility.
