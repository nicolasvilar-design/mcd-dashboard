# Color Palette

McDonald's Dashboard uses a comprehensive color palette designed for accessibility and brand consistency.

## Primary Colors

### McDonald's Black
- **Value:** `#292929`
- **Usage:** Primary text, UI elements, headers
- **Accessibility:** ✅ WCAG AA contrast

### McDonald's Red
- **Value:** `#DA291C`
- **Usage:** Primary actions, brand elements, CTA buttons
- **Accessibility:** ✅ WCAG AA contrast

## Secondary Colors

### McDonald's Green
- **Value:** `#1F6437`
- **Usage:** Success states, complementary UI
- **Accessibility:** ✅ WCAG AA contrast

## Neutral Colors

| Color | Value | Usage |
|-------|-------|-------|
| White | `#FFFFFF` | Default background |
| Light Gray | `#F5F5F5` | Subtle backgrounds |
| Medium Gray | `#E8E8E8` | Borders, dividers |
| Dark Gray | `#757575` | Secondary text |
| Black | `#212121` | Dark backgrounds |

## Status Colors

| Status | Color | Value | Usage |
|--------|-------|-------|-------|
| Success | Green | `#4CAF50` | Positive feedback |
| Warning | Yellow | `#FFC107` | Cautionary feedback |
| Error | Red | `#F44336` | Error feedback |
| Info | Blue | `#2196F3` | Informational feedback |

## Usage Guidelines

- **Primary Text:** `#292929` on white backgrounds
- **Secondary Text:** `#757575` for supporting information
- **Tertiary Text:** `#BDBDBD` for hints, placeholders
- **On Primary:** `#FFFFFF` for text on dark backgrounds

---

**Note:** All colors meet WCAG AA accessibility standards for contrast ratios.
