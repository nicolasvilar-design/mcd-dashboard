# Spacing System

McDonald's Dashboard uses an 8-point spacing system based on the base unit of 4px. This ensures consistency, scalability, and easier responsive design.

## Spacing Scale

All spacing values are multiples of 4px:

| Token | Value | Use Case |
|-------|-------|----------|
| 0 | 0px | Remove spacing |
| 1 | 4px | Tight spacing (borders, small gaps) |
| 2 | 8px | Compact spacing (icon/text pairs) |
| 3 | 12px | Small spacing (form field margins) |
| 4 | 16px | Standard spacing (section padding) |
| 5 | 20px | Medium spacing (component spacing) |
| 6 | 24px | Large spacing (section margins) |
| 8 | 32px | Extra large spacing (major sections) |
| 12 | 48px | Container spacing |
| 16 | 64px | Extra large sections |
| 20 | 80px | Page-level spacing |
| 24 | 96px | Full page sections |

## Usage Guidelines

### Padding (Internal Spacing)
- **Components:** Use space-2 to space-5 (8px-20px)
- **Cards:** Use space-4 to space-6 (16px-24px)
- **Containers:** Use space-6 to space-8 (24px-32px)

### Margin (External Spacing)
- **Between elements:** Use space-2 to space-4 (8px-16px)
- **Between sections:** Use space-6 to space-8 (24px-32px)
- **Between major blocks:** Use space-12+ (48px+)

### Gaps (Flex/Grid)
- **Compact layouts:** Use space-1 to space-3 (4px-12px)
- **Standard layouts:** Use space-4 to space-6 (16px-24px)
- **Loose layouts:** Use space-8+ (32px+)

---

**Note:** Consistent spacing creates visual harmony and improves usability.
