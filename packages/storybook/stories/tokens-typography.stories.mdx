# Typography Tokens

McDonald's Dashboard typography system uses **Speedee** for headings and **Segoe UI** for body text.

## Headline Styles

Structured hierarchy for content organization.

| Level | Size | Weight | Line Height | Use Case |
|-------|------|--------|-------------|----------|
| H1 | 28px | 400 | 1.3 | Main page title |
| H2 | 24px | 400 | 1.3 | Section header |
| H3 | 24px | 400 | 1.3 | Content heading |
| H4 | 20px | 400 | 1.4 | Subsection |
| H5 | 18px | 500 | 1.4 | Block title |
| H6 | 16px | 600 | 1.4 | Label heading |

## Body Styles

Main content typography, optimized for readability.

| Level | Size | Weight | Font Family |
|-------|------|--------|-------------|
| Body-01 | 16px | 400 | Segoe UI |
| Body-02 | 14px | 400 | Segoe UI |
| Body-03 | 12px | 400 | Segoe UI |

## Label Styles

For form labels, badges, and small text.

| Label-02 | 14px | 500 | Segoe UI |
